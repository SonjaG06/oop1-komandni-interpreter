# Komandni interpreter (OOP1)

Konzolni interpreter komandi u C++20, projekat iz predmeta Objektno orijentisano programiranje 1.

Podržane komande: `echo`, `prompt`, `time`, `date`, `touch`, `truncate`, `rm`, `wc`, `tr`, `head`, `batch`, `exit`.
Podržani su preusmeravanje ulaza/izlaza i cevovodi (`|`).

## Prevođenje

```
cmake -B build
cmake --build build
./build/projekat
```
